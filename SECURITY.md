# Security Policy

Daydream is a developer alpha. Only the latest `main` branch receives security
fixes.

## Reporting a vulnerability

Email `daydream@turtledev.net`.

Do not open a public issue for a vulnerability. Do not attach private recordings,
screenshots, audio, transcripts, OCR output, window titles, prompts, API keys,
embeddings, database files, or unredacted logs.

Include:

- The affected commit or version.
- The operating system and desktop environment.
- Reproduction steps using synthetic data.
- The expected and observed behavior.
- The likely privacy or security impact.

There is no fixed response-time guarantee during the alpha period, but valid
reports will be reviewed and handled privately before public disclosure where
practical.
