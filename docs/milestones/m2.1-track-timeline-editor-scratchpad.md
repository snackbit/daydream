# Milestone M2.1 Scratchpad: Track Timeline Editor

## Planning Notes

- User wants Ableton/FL Studio style timeline handling, not a small visual patch.
- Primary workflow: select lanes, clips, and time spans; inspect/edit them in
  the sidebar; prepare for later redaction/cut actions.
- Captured MKV files stay immutable. Future editing should be metadata layered
  over source media.
- M2.1 is UI/UX and state architecture first. Persistence comes later.

## Implementation Notes

- Existing timeline code owns zoom, follow-scroll, waveform tile loading,
  pointer seek, ruler rendering, and lane rendering in one component.
- Existing sidebar is static recording metadata only and needs a real selection
  inspector surface.
- Implemented editor state as a session-local Zustand store under the studio
  feature.
- Split the timeline into shell, extracted UI parts, lane rendering, and a
  pointer selection hook to keep the main file under the max-lines lint warning.
- Added dnd-kit sortable wrappers and kept the lane header compact with only a
  grab handle for reordering.
